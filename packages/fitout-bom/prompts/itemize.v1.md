# Itemization contract v1

按区域识别可采购的物品，多角度拍到的同一物品合并，保留每个来源图的编号及局部位置。一种产品一行，名称应能直接用作采购搜索词。

桌、椅、卡座及定制柜按 custom 处理，给出四至六个主要构件提示。灯具、标准装饰及设备按 whole 处理，不拆小零件。小五金及耗材合并。

照片推测出的尺寸和数量必须标记 estimated。明确区分照片可见数量与整店需求量。生成图、修复图及复原图只能支持款式判断，不能证明真实尺寸或数量。不要填写任何价格或供应商身份。

输出必须通过 ItemCandidate schema 校验，再由 reviewItems 人工确认才能进入物料单。
